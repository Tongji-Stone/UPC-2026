# 电脑 A：整合、参数反演与概率预测

先阅读 `协作任务/协作约定.md`、`协作任务/完整任务书.md`、根目录 `Agents.md` 和 `赛题.md`。在 `codex/integration` 分支工作，先检查现有目录和依赖，保护已有文件。

## 工作内容

1. 负责公共工程结构和接口协调，按 B、C 的实际交付适配，不让对方等待完整工程。
2. 建立简化预测器，包括 M0、M1 与独立的 M2 匀加速度模型；用任务书给定的三个简化参考值核对，明确各自输入和计算方法。
3. 根据仿真接口实现带参数边界的加权最小二乘；用已知参数的合成轨迹验证。加入雅可比、相关性、不同初值和正则化诊断。
4. 实现可复现的带先验概率预测，比较仅用 0、0.05 秒与使用 0、0.05、0.10 秒的结果。前者严禁使用 0.10 秒观测；两次预测采用一致的模型和先验原则。
5. 输出落点分布、众数、均值、协方差、68%/95% 区域和明确分母的进球概率，记录观测误差及先验假设。
6. 依次整合 B、C 的成果，完成模型比较、敏感性分析、图表及技术报告；更新 Claude 风格配色的 HTML 探索树。

从最小可验证版本开始，反演模块等待仿真接口时先用简化模型推进。每阶段记录命令、结果和未完成事项，测试通过后再进行下一步。计算与绘图分离，保存中间数据和随机种子。
