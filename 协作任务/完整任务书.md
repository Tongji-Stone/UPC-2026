# IUP Problem B：足球三维轨迹预测与不确定性分析——本地开发任务书

## 一、项目目标

开发一套模块化、可复现的足球三维飞行轨迹预测系统，用于国际大学生物理竞赛（IUP）Problem B。

采用较完整的 M5 空气动力学模型作为基础，但通过配置开关退化为简单物理模型，用于消融实验和模型复杂度比较。

项目最终需要解决四个问题：

1. 根据足球初始或中途运动状态，求解完整三维飞行轨迹。
2. 根据极少量位置观测，反演初速度及未知空气动力学参数。
3. 预测足球穿过球门平面的位置，并估计不确定性。
4. 利用真实足球追踪数据及合成数据，验证预测准确性，分析参数敏感性和模型复杂度的影响。

这是一项物理建模和数值分析项目，不需要开发网页或复杂 GUI。优先保证物理正确性、算法可靠性、实验可复现性及代码可维护性。

开发环境：Windows 11，Python 3.11 或兼容版本。

建议使用 NumPy、SciPy、Pandas、Matplotlib、pytest，必要时使用其他成熟科学计算库。

## 二、竞赛题目

已知：

- 球门平面：x = 11 m。
- 球门横向范围：-3.66 ≤ y ≤ 3.66 m。
- 球门高度：0 ≤ z ≤ 2.44 m。

足球球心的观测数据：

| t (s) | x (m) | y (m) | z (m) |
|---|---|---|---|
| 0 | 0 | 0 | 0.11 |
| 0.05 | 1.50 | 0.45 | 0.44 |
| 0.10 | 2.96 | 0.86 | 0.74 |

要求：

- 在 t = 0.05 s 时，仅使用此前可获得的观测预测球门落点。
- 在 t = 0.10 s 时，使用新增观测更新预测。
- 计算最可能的落点、预测区域及不确定性。
- 开发可推广到其他射门的通用算法。
- 使用独立数据验证预测精度。

不得把 0.10 s 的位置用于生成 0.05 s 时刻的预测。

## 三、M5 完整物理模型

### 3.1 状态变量

定义：

- 位置 r = (x, y, z)
- 速度 v = (vx, vy, vz)
- 角速度 ω = (ωx, ωy, ωz)

完整动力学状态为：

X = (r, v, ω)

默认物理参数：

- 足球质量 m = 0.43 kg。
- 足球半径 R = 0.11 m。
- 空气密度 ρ = 1.2 kg/m³。
- 重力加速度 g = 9.81 m/s²。
- 截面积 A = πR²。
- 空气动力黏度 μ 采用有依据的标准参考值。

所有参数必须能通过配置文件修改。

### 3.2 作用力

完整模型：

m dv/dt = Fg + Fd + Fm

其中：

**重力**

Fg = -mg ez

**空气阻力**

Fd = -½ ρ Cd A |u|u

其中 u = v - vwind，是足球相对于空气的速度。

**马格努斯力**

Fm = ½ ρ Cl A |u|² n

其中 n 是由 ω × u 确定的单位方向。

当角速度与速度平行，或者叉积模长接近零时，应采取数值稳定的处理，避免除零。

### 3.3 变空气动力学系数

需要实现：

Cd = Cd(Re, Sp)

Cl = Cl(Re, Sp)

其中：

Re = ρ|u|(2R)/μ

Sp = R|ω|/|u|

优先参考已发表足球空气动力学实验文献建立经验拟合关系，不要求开展 CFD 计算。

至少支持三种系数模型：

1. 常数系数。
2. 仅随雷诺数变化。
3. 同时考虑雷诺数与旋转参数。

把每种系数模型的公式、参数来源、适用范围和外推限制写入文档。

严禁把未经验证的拟合曲线当作实验真值。

### 3.4 自旋衰减

实现可选的角速度衰减模型：

dω/dt = -kω ω

默认可以关闭。

需要比较有无自旋衰减对约 0.4 s 飞行轨迹的影响，判断该效应是否值得保留。

### 3.5 风速

支持三维恒定风速向量：

vwind = (wx, wy, wz)

默认无风。

风速应作为独立参数或外部环境输入。由于短时间观测不足，不应假定可以同时准确识别全部风速和自旋参数。

## 四、模块化设计：完整模型必须能够退化

不要为每一级模型重复编写独立的运动方程。

统一使用状态导数函数，按照配置组合各物理项。

要求支持：

| 模型 | 重力 | 阻力 | 马格努斯力 | 变气动系数 | 风 | 自旋衰减 |
|---|---|---|---|---|---|---|
| M0 | 关闭 | 关闭 | 关闭 | 关闭 | 关闭 | 关闭 |
| M1 | 开启 | 关闭 | 关闭 | 关闭 | 关闭 | 关闭 |
| M2 | 经验匀加速度模型 | — | — | — | — | — |
| M3 | 开启 | 开启 | 关闭 | 关闭 | 关闭 | 关闭 |
| M4 | 开启 | 开启 | 开启 | 关闭 | 关闭 | 关闭 |
| M5 | 开启 | 开启 | 开启 | 开启 | 可选 | 可选 |

注意 M2 属于经验运动学模型，应作为独立的可比较预测器，而不是错误地把它当成一种受力组合。

统一提供接口，例如：

```python
simulate(initial_state, physics_config, t_eval)
predict_goal(initial_state, physics_config)
```

代码结构要清楚地区分：

- 物理参数
- 气动力系数
- 运动方程
- 数值积分
- 参数估计
- 不确定性传播
- 数据处理
- 评价指标
- 可视化

推荐采用 dataclass、类型标注、配置文件和模块化 Python 包结构。

不要将所有功能写在一个大脚本中。

## 五、正向数值求解

使用 `scipy.integrate.solve_ivp` 或其他成熟 ODE 求解器。

要求：

1. 支持任意合法初始位置、速度、自旋。
2. 支持自由选择积分时间和精度。
3. 检测足球首次穿越指定平面 x = 11 m 的事件。
4. 检测足球与地面接触。
5. 区分到达球门平面之前已经落地的轨迹。
6. 输出轨迹、速度、加速度、各分力和关键事件时间。

不得仅使用固定时间网格上最接近 x = 11 的点近似落点，应使用连续事件检测或插值求交。

加入基础物理测试：

- 只有重力时，应与解析抛体公式一致。
- 没有外力时，应符合匀速直线运动。
- 纯阻力应耗散机械能。
- 不应出现 NaN、无穷值或明显非物理状态。

## 六、反向问题：根据稀疏观测估计运动参数

这是项目的重点。

### 6.1 统一参数估计接口

输入：

- 观测时间序列
- 三维位置
- 位置测量误差假设
- 物理模型配置
- 参数先验或约束

输出：

- 参数估计
- 参数的不确定性
- 数据拟合残差
- 可辨识性诊断
- 预测轨迹

### 6.2 最小二乘基线

首先实现加权最小二乘方法：

min Σ [r_sim(ti; θ) - r_obs(ti)]ᵀ Σi⁻¹ [r_sim(ti; θ) - r_obs(ti)]

使用 `scipy.optimize.least_squares` 等成熟算法。

对参数设置合理物理边界。

但是必须认识到：

在 0.05 s 时，只有一个非初始位置观测，不能唯一识别初速度、自旋和气动系数。

在 0.10 s 时，尽管有两个非初始位置观测，也不能保证完整 M5 参数可辨识。

不得仅因为优化器收敛，就宣布找到了真实角速度或真实阻力系数。

### 6.3 参数可辨识性

至少实现：

- 参数雅可比矩阵分析。
- 参数相关性分析。
- 不同初值下的拟合结果比较。
- 参数约束与正则化实验。

讨论哪些参数能够由早期位置可靠估计，哪些只能依赖先验。

### 6.4 概率参数反演

在确定性最小二乘之外，实现至少一种概率推断方法：

- 带先验的蒙特卡洛重要性采样；
- 贝叶斯参数估计；
- 粒子滤波；
- 或其他适合低维非线性动力学的方法。

优先选择实现成本合理、容易验证的方案。

当观测数据不足时，不强求唯一参数，而是保留多个与观测相容的可能运动状态。

### 6.5 两次预测

分别生成：

**预测 A**

只允许使用 t = 0 和 t = 0.05 s 的观测。

**预测 B**

允许使用 t = 0、0.05 和 0.10 s 的观测。

两次预测必须使用相同的模型定义和一致的先验原则。

比较新增观测如何改变：

- 最可能落点。
- 预测均值。
- 落点协方差。
- 预测区间。
- 进球概率。

## 七、不确定性分析

不确定性至少分为：

1. 位置测量误差。
2. 初速度估计误差。
3. 气动参数不确定性。
4. 自旋参数不确定性。
5. 模型结构不确定性。

题目没有给出观测误差，因此必须明确声明误差水平是假设。

建议测试：

- σ = 0 m，理想观测。
- σ = 0.005 m。
- σ = 0.01 m。
- σ = 0.03 m。

可进一步扩展。

使用蒙特卡洛或其他可靠方法传播不确定性。

输出：

- 球门落点二维概率分布。
- 最可能落点与均值。
- 68% 和 95% 预测区域。
- 进球概率。
- 各不确定性来源的影响。

注意：最可能落点不一定等于概率分布均值。

计算进球概率时考虑足球半径和球门边界。

此外，要区分“预测落点在球门范围内”和“足球完整穿过球门”。

- 运算耗时。

不能用完整真实轨迹拟合参数后，再用同一轨迹宣称提前预测成功。

## 九、敏感性分析

至少研究以下参数：

- 初速度大小。
- 水平射门角度。
- 初始仰角。
- 自旋大小。
- 自旋轴方向。
- 阻力系数。
- 升力系数。
- 空气密度。
- 风速。
- 位置测量误差。
- 可获得的观测时长。

### 方法

首先进行单因素敏感性分析。

改变一个参数，其余参数保持不变，计算球门落点变化。

然后进行全局敏感性分析，例如：

- 蒙特卡洛参数扫描。
- Morris 方法。
- Sobol 敏感性分析（条件允许时）。

由于部分参数存在相关性，进行 Sobol 分析时需要说明输入分布及独立性假设，避免不合理的结果解释。

建议重点研究：

1. 不同参数对横向落点 y 的影响。
2. 不同参数对竖直落点 z 的影响。
3. 哪些参数造成最大的预测不确定性。
4. 观测时间由 0.05 s 增加到 0.10 s 后，哪些参数更容易识别。
5. 复杂模型是否一定优于简单模型。

程序应当可以通过清晰的命令或配置实现：

- 选择物理模型。
- 输入任意射门观测数据。
- 计算预测落点。
- 输出不确定性。
- 执行模型对比。
- 运行真实数据测试。
- 执行敏感性分析。

## 十五、工作原则

这是一个 48 小时竞赛背景下的研究项目。

优先完成可验证的核心功能，再增加复杂度。

在开发过程中：

- 先检查当前工作目录，若存在已有项目，应保持兼容，不覆盖无关文件。
- 可以自行进行合理的非破坏性技术决策。
- 遇到参数缺失，应提出明确假设并记录。
- 遇到理论不确定性，应查询原始文献。
- 遇到数据集不可访问，应记录限制并切换备选方案，不尝试绕过访问权限。
- 不编造实验数据、准确率和论文结论。
- 对尚未完成或未验证的功能明确标注。
- 定期运行测试，避免最后集中调试。

尤其注意：**不得通过人为选择有利的测试轨迹、利用后续观测拟合模型，或者调整测试集来制造虚假的预测精度。**

开始工作时，先检查项目目录和依赖环境，建立简洁的实施计划，然后立即实现第一阶段。每完成一个阶段，报告：

1. 已完成内容。
2. 实际运行的验证测试。
3. 已发现的问题。
4. 下一阶段工作。

最终以真实数据验证结果和不确定性分析为核心，形成可用于物理建模竞赛论文的可靠研究成果。
