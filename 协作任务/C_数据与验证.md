# 电脑 C：真实数据与独立验证

先阅读 `协作任务/协作约定.md`、`协作任务/完整任务书.md`、根目录 `Agents.md` 和 `赛题.md`。在 `codex/data-validation` 分支工作。先检查项目和依赖，建立简洁计划；数据准备与 A、B 并行，不等待物理模型完成。

## 工作内容

1. 优先核查任务书列出的 DFL 和 ball3d 原始资料，确认字段、实际采样时间、三维坐标和单位、许可、文件大小及访问方法；记录来源。SoccerNet-GAR 按其访问规则处理。优先获取轨迹文件，不下载大批视频。
2. 建立原始数据与处理数据分离的流程；转换到米、秒和统一坐标约定，保留原始时间。检查缺失值、重复时间、明显异常和可用的自由飞行片段。
3. 设计固定且可复现的测试样本选择规则和早期观测截断规则，严禁未来帧参与输入。25 Hz 数据按真实帧时间测试。区分真实点球球门与一般飞行轨迹的虚拟预测平面。
4. 建立可独立测试的评价函数：二维落点误差、均值、中位数、90% 分位、预测区域覆盖率、合适的概率评分和运行时间。明确统计分母和无穿越情况的处理。
5. 用真实公开数据生成至少一个可复现的处理和验证示例；若受访问、数据质量或时间限制无法完成，记录证据并切换备选数据，先用合成轨迹验证流程。不要把合成结果写成真实数据结果。
6. 提供统一数据格式、样本清单、获取与运行命令、测试和中文阶段报告。大型原始数据不提交 Git；保留来源、许可和处理步骤。

与 A 对齐预测器输入输出后接入模型比较；各模型使用相同样本和观测窗口。计算和绘图分离，随机过程记录种子。交接时告知 A 分支、提交号、接口、实际运行结果和未完成事项。
