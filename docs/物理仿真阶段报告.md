# 足球飞行：正向仿真阶段记录

足球离脚后，在重力作用下向下弯曲；空气阻力会减慢球速，自旋还会让球偏转。最简单的方案是用匀速或抛体运动描述，更完整的方案则把这些力一起放入运动方程，逐步计算球的位置和速度。

已有实验显示，阻力和偏转程度会随速度、自旋及球的表面结构变化。实际计算因而需要一套能切换受力、并允许输入实验系数的方法。本阶段建立了统一的数值模型，以连续事件确定球心到达球门平面或落地的时间。

## 完成内容

- M0 为匀速，M1 加入重力，M3 加入阻力，M4 再加入马格努斯力。M5 可以输入与雷诺数、自旋参数有关的系数，以及风和自旋衰减。M2 由整合部分作为独立经验模型处理。
- 模型输出时间、位置、速度、自旋、加速度、各分力及首先发生的事件；从地面向上起飞时不会立即判为落地。坐标和单位采用任务书约定。
- 固定系数默认取阻力 0.25、升力 0.2，作为可修改的演示参数。变系数可用 `reynolds_table` 或 `reynolds_spin_table` 载入实测数据插值；表格范围外会报错，方便发现数据覆盖不足。
- 可选 `linthorne_patel_coefficients` 实现 [Linthorne 和 Patel（2011）](https://www.jssm.org/volume10/iss1/cap/jssm-10-203.pdf)第 3、4 式：转速 f 用转/秒时，升力系数为 `0.25 × (1 − exp(−0.5f))`，阻力系数为 `Cd0 + 0.014f`。文中对速度约 25～35 m/s 的球采用零自旋阻力系数约 0.1～0.2；该论文研究足球凌空踢，应用到三维侧旋需要作模型假设。函数所用半径和空气运动黏度须与物理配置保持一致。
- 对零相对风速和自旋方向与运动方向平行的情况，气动力计算保持有限。升力方向使用角速度与相对空气速度的叉积；将横向自旋实验关系推广到倾斜自旋轴时，升力大小乘以自旋轴与相对气流夹角的正弦，使轴趋于平行时升力连续趋零。这一步是三维近似。

## 约 0.4 秒的示例

下面的例子用初速度 `(25, 0, 8)` m/s、自旋 `(0, 0, 30)` rad/s，从球心高度 0.11 m 起飞。演示时取阻力系数 0.25，并人为设升力系数 `min(1.5 × 自旋参数, 0.4)`；这一关系只是为展示功能而设，后续需用测量数据替换。

| 条件 | 0.4 秒时位置 (m) | 0.4 秒时自旋 (rad/s) |
|---|---|---|
| 无风、自旋不衰减 | (9.354, 0.481, 2.356) | (0, 0, 30.00) |
| 沿 y 正方向 2 m/s 风 | (9.390, 0.533, 2.356) | (0, 0, 30.00) |
| 无风、自旋衰减率 1/s | (9.358, 0.424, 2.356) | (0, 0, 20.11) |

在这个设定下，风使横向位置增加约 5.2 cm；自旋衰减使横向位置减少约 5.8 cm。衰减参数和系数关系不同，结果也会变化。使用固定升力系数时，自旋衰减只改变角速度大小，不改变非零自旋产生的升力大小，因此比较衰减影响时需要使用随自旋变化的系数。

## 来源与下一步

阻力和升力按照 `1/2 × 空气密度 × 迎风面积 × 相对风速² × 对应系数` 计算；参考 [NASA 足球阻力介绍](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/drag-on-a-soccer-ball/) 和 [NASA 足球弯曲运动介绍](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/bending-a-soccer-ball/)。雷诺数采用球直径和空气运动黏度，自旋参数为半径乘角速度大小再除以相对风速；参见 [足球轨迹实验论文](https://eprints.whiterose.ac.uk/id/eprint/98035/1/1-s2.0-S1877705812016414-main.pdf)。不同足球的系数需要对应实验数据；下一步可整理目标足球在所需速度、自旋范围内的数据后输入插值表。

运行检验：PowerShell 中设置 `$env:PYTHONPATH='src'`，再执行 `python -m unittest discover -s tests -p test_physics.py -v`。测试覆盖匀速与重力解析解、起飞和事件、阻力能量下降、数值边界及自旋衰减。
