# 报告结构与四模型重算

论文保持八章：引言、模型准备、模型建立、模型求解、灵敏性分析、其他因素、小结和模型评价。数据来源及反演参数放在附录。

当前 M3 为恒合力模型，M4 为恒定 CD 与线性 CL=alpha Sp。第四章以两次精准推射和一次大力抽射展开，统一列出早期残差、后续路径 RMSE/点数、球门误差与终止状态。第五章给出单参数响应、2 mm 位置约束网格和十万条蒙特卡洛轨迹。

当前数值与来源见 [线性自旋复算](linear_spin_recalculation.md)，第五章设置见 [灵敏性分析](灵敏性分析与复现.md)。重新计算使用 scripts/reproduce_report.ps1 -Recompute；计算、绘图、数值表生成与编译核查分开执行。
