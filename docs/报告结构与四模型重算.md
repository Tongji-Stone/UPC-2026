# 报告结构与四模型重算

本次报告重组为八章，主模型采用恒定自旋三力方程，旋转阻尼移入第六章，第五章灵敏性分析待做。Introduction 保留主体内容，1.2 增加章节导读。

题目 M4 初速度为 [30.406302947799468, 9.425592132173508, 6.906426894571296] m/s，自旋为 [-49.09028517146845, -31.483351948356475, -112.26563317044834] rad/s，两项力修正为 1.000100、1.000000。球门交点为 (2.682645, 1.959231) m，时间 0.402649 s。详细残差和分级选解记录保存在 problem 案例 JSON。

受控无旋转实测落距 21.9 m，M4 预测 21.871 m。旋转实验仅比较已公开的空间轨迹片段；原 PDF、实测标记、坐标标定及制图代码均随项目保留。

相同初始条件加入二次旋转阻尼后，球门交点移动 0.146880 m，为 11 m 距离的 1.335%；自旋减少 41.243%。黏性/惯性力矩比约 9.8e-05。正文按实际结果陈述其影响。

比赛对照逐项记录所有五个案例和四类模型，包括触地、提前终止与拟合失败。后续帧只用于验证目标。原有耦合模型结果通过 SHA256 检查保存原样。

## 反演选解

先最小化两次位置的六个坐标残差，再选择修正系数最接近 1 的解；M4 在等价解中选自旋最小者。位置目标允许差额 6e-12 m²，系数目标允许差额 1e-8。M3 用单位旋转轴表示方向，不将其单位模长解释为实测转速。
