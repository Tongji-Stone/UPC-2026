# 第六章：简化假设检验与复现

## 当前旋转阻尼设定

6.2 固定采用 MuJoCo 的默认旋转阻力参数 Cangular=1.5，该量不参与拟合。由题设初始位置及0.05、0.10 s位置，重新反演三个初速度分量、两个自旋方向角、CD 和 alpha，共七项；初始自旋模长为30 rad/s。沿用第四章的六组旋转方向初值、参数边界及最小位置残差选解方法。

自旋在到门时下降至25.6921 rad/s，下降14.36%。阻尼模型预测交点为(2.6397, 1.9515) m，到达时间0.399139 s；原M4为(2.6159, 1.9526) m、0.398967 s。两交点相差2.38 cm。图中两条曲线分别为恒定自旋M4与固定默认阻尼的模型。

以初始自旋估计，黏性旋转力矩与二次力矩之比约4.13×10⁻⁴；加入黏性项后，交点再变化约1.58×10⁻⁵ m。第四、五章模型和原始结果保持不变。

## 其余两项检验

题设轨迹雷诺数约3.75×10⁵—4.77×10⁵，正文结合图19及足球专用系数所包含的表面平均作用，讨论球形包络。6.3保持原结果：全部水平风向扫描的保守风速界限为0.94 m/s，最大交点偏移约4.953 cm。顺风、逆风、左侧风、右侧风的界限分别为1.79、1.69、1.13、1.15 m/s。

## 数据与复现

所有当前数据集中在 results/chapter6/。torque/fit.json 保存固定默认值下的七参数结果及六组优化记录；constant_spin.csv、default_damping.csv 是两条主图轨迹，with_viscosity.csv 是黏性核查。wind/保持既有风速计算。旧的八参数拟合、范围扫描与其附录表退出当前流程。

安装依赖、将 src 加入 PYTHONPATH 后，从仓库根目录执行：

```powershell
./scripts/reproduce_chapter6.ps1 -Python python
```

默认复用当前计算记录，加 -Recompute 可重新计算。计算、绘图、数值刷新、核验分别由 chapter6_compute.py、chapter6_plot.py、chapter6_paper_values.py、chapter6_verify.py 完成。数值脚本只刷新各版 main.tex 的 CHAPTER6_RESULTS 区域。

分别在 paper/ 和 _中文版/ 运行三遍：

```powershell
xelatex -no-shell-escape -interaction=nonstopmode -halt-on-error main.tex
```

随后运行 python scripts/chapter6_pdf_check.py，检查导出件与源文件、引用和页面边界。每版仍为一个完整main.tex，图内使用英文。中英文源文件与编译PDF同步提交至Git。
