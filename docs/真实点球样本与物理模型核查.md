# 真实点球样本与物理模型核查

真实比赛的位置追踪记录可以用来检查计算轨迹是否贴近足球实际走过的位置。先用比赛事件找到射门，再把同一时间附近的球位置连起来，并在真实球门所在的平面比较穿越位置。

## 找到的点球

公开数据 J03WOH 为杜塞尔多夫对雷根斯堡的比赛。[数据论文](https://www.nature.com/articles/s41597-025-04505-y)说明它同时提供事件和球的位置数据；位置数据每秒 25 帧。与本地球轨迹相同比赛的事件与比赛信息从 [数据集镜像](https://huggingface.co/datasets/pysport/idsse-data)获取，数据许可为 CC BY 4.0。

事件 `18232100000995` 标为点球、射门成功。其时间为 `2022-08-26T19:54:15.640+02:00`；事件文件此条未给出同步帧。球的位置在此时间后 0.88 秒开始出现连续运动，帧 128954～128965 从 `(41.56, -0.04, 0.11)` 运动到 `(53.41, 3.24, 1.17)`，历时 0.44 秒。此前长时间重复 `(53.18, -12.33, 0)`，不作为这段射门轨迹；首个运动步长也明显较后续步长小，拟合时宜检查其影响。

场地元数据给出长 105 m、宽 68 m。以场地中心为坐标原点时，两个门线位于 x=±52.5 m；该球朝 x 增大的方向飞行，因此对照 x=52.5 m 的实际门线。位置坐标和以场地中心为原点的约定可参考 [DFL 追踪数据研究](https://www.frontiersin.org/journals/sports-and-active-living/articles/10.3389/fspor.2021.676179/full)。球在帧 128964 的 x=52.39 m，下一帧 x=53.41 m；逐分量线性插值得 y=2.919 m，Z 原始值为 1.179。论文确认 x、y 为米，称 Z 为球高，但未注明 Z 的单位或基准；当前计算暂按米处理，待进一步核对。

`scripts/inspect_real_penalty.py` 从原始事件和已提取的球轨迹生成 `results/b_real_penalty/trajectory.csv` 与 `event_and_crossing.json`。片段结束于首次越过门线后的第一帧。事件时间、球位置突变和首帧均需保留，方便复核对齐。

## 物理模型怎样比较

整段位置可用于拟合初始位置和初速度，先比较逐帧三维误差，再比较模型和插值球轨迹在真实门线的穿越位置。拟合时可以给初速度、球质量、空气密度和气动系数设置合理范围，并检查轨迹是否在穿门之前触地或受到球员、门柱和球网接触。拟合位置本身也有测量误差，首帧固定和首帧可调整两种处理值得比较。

多个位置点使估计阻力和自旋成为可能；实际约束能力取决于数据精度、球的飞行时间和变化幅度。应先固定球质量、半径及环境，再分别尝试只拟合速度、加入阻力、加入自旋，比较不同初值和参数范围下的结果。对同一段用于拟合的数据，轨迹误差描述贴合程度；需要用其他射门或未参与拟合的轨迹片段检验可迁移性。球本身转速并未在数据中直接给出。

当前采用的 [Linthorne 和 Patel 系数关系](https://www.jssm.org/volume10/iss1/cap/jssm-10-203.pdf)来自足球凌空踢研究；其关于零自旋阻力系数的讨论涉及 25～35 m/s。当前代码把该关系用于点球三维轨迹，并用夹角正弦处理倾斜自旋轴，是需要由数据检验的推广。下一步可对比固定系数、论文系数和经轨迹拟合的系数，以及不同自旋轴的结果。
