# 灵敏性分析与复现

第五章采用题目给定三次位置的独立参考算例，沿用恒定自旋、静止空气 M4 关系。质量为 0.43 kg，半径为 0.11 m。最新第四章的三次真实点球、正向算例及反演边界保持原样。参考状态来自原论文版本 91bda30，完整精度状态冻结在 data/sensitivity_v2/representative_state.json，以保留此前核定的灵敏性结果。

## 分析设置

单参数分析涉及球速、速度方位角和仰角、自旋大小、旋转轴方位角和仰角、阻力与升力修正、空气密度。各取 41 个值，共 369 条轨迹。球速范围为 ±5%，其余非零标量为 ±10%，角度为 ±2°。到达时间图使用扰动除以扫描半宽的统一横轴，纵轴仍为毫秒。

约束分析保持 t=0、0.05、0.10 s 的位置一致。两项气动力修正各在 0.8–1.2 内取 17 点，使用邻近解延续并在九个代表点补充初值，共记录 316 次求解。196 个网格点得到可行状态，去除同点重复后保留 198 个状态。24 次局部约束细化中，22 个候选满足残差和边界判据。搜索限制总球速不超过 35 m/s、总自旋不超过 200 rad/s，最大坐标残差不超过 1e-7 m。最终范围来自已求得的相容状态。

蒙特卡洛主样本为 100000 条，种子为 20261108，各参数按完整扰动区间独立均匀抽样。另用种子 20261109、20261110 各计算 10000 条。主积分步长为 0.002 s，三次 Hermite 插值定位事件；70 条随机或极值轨迹与独立 DOP853 对照，2000 条轨迹进行步长减半检查。samples.npz 保留全部输入、状态与结果，samples.csv.gz 为对应压缩表格。

平行坐标使用展示种子 20261112，从主样本均匀无放回选择 400 条，382 条可通过球门、18 条过高。输入按声明范围、输出按完整主样本极值缩放到 0–1。总体比例使用完整十万条轨迹。

## 快速重建图表与论文

在仓库根目录安装依赖后执行：

    python -m pip install -e ".[report,test]"
    ./scripts/reproduce_sensitivity.ps1

默认复用仓库已有结果，重建图表、同步双语数值、编译两版 PDF 并核查。需要重新计算时执行：

    ./scripts/reproduce_sensitivity.ps1 -Recompute

也可逐项运行：

    python -B scripts/sensitivity_v2_compute.py
    python -B scripts/sensitivity_v2_refine.py
    python -B scripts/sensitivity_v2_check.py
    python -B scripts/sensitivity_monte_carlo_compute.py
    python -B scripts/build_sensitivity_assets.py

正文采用四阶龙格–库塔积分；独立积分器、解析极限、差分步长检查、原数据散列、双语公式与表格、编译引用等结果保存于 results/sensitivity_v2/。双语核查展开第四、五章后比较公式和表格数值；原第四章源码、表格及模型文件的散列单独核对。
