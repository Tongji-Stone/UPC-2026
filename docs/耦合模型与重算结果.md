# 三力与旋转阻尼耦合模型

球在空气中同时减速和改变自旋。阻力、升力随来流速度和旋转强度变化，旋转阻尼又会改变之后的气动力，因此采用位置、速度和自旋共九个状态联合积分。主实现位于 `src/football/physics/model.py`；反演和预测使用同一个 `state_derivative`。

## 模型与参数来源

平动包含重力、阻力和 Magnus 升力；转动仅包含旋转阻尼力矩。CD、CL 采用 Kiratidis–Leinweber 2018 年完整关系，CQ 采用 Grad 补充材料和 MuJoCo 3.8.1 球形化简得到的二次项与黏性项。没有叠加旧的线性自旋衰减。

参考球质量0.43 kg、半径0.11 m、重力加速度9.81 m/s²及薄球壳惯量可追溯至 Maponi–Piombin 2025 年的参数和模型。空气密度1.2 kg/m³引用 Asai 2007 年实验，运动黏度1.5×10⁻⁵ m²/s、无风、三维升力的 sinθ 投影为明确的参考设定；动力黏度统一由ρν计算。角阻尼强度1.5为 MuJoCo 已公开默认值，未将其称为足球实测标定值。

初速度与初始自旋六个分量通过早期位置联合拟合，不固定自旋、不增加参数先验、不假设相机误差。数值初值覆盖零自旋，以及2、6、10转/秒绕正负坐标轴旋转，共19个起点。起点不是实际自旋假定，也不是拟合上限。

## 自洽性检查

在上述明确设定下，九个一阶方程闭合。球壳惯量各向同性，陀螺项ω×Iω为零；阻力反向于相对速度，Magnus 力与其正交，旋转阻尼反向于自旋。无风时，总机械能变化等于阻力功率加转矩功率，非正。

自动检查包括 CQ 的归一化换算、解析自旋衰减、能量恒等式、积分收敛、零速度和零自旋极限、禁止双重阻尼、合成观测反演和真实数据早期输入规则。方程的机械一致性与初始状态能否唯一辨识分别报告。

## 实际计算结果

题目给定三点对应两组不同的近等最优拟合，最大坐标残差均小于10⁻⁸ m。其球门交点约为：

|拟合|y/m|z/m|到达时间/s|
|---|---:|---:|---:|
|A|2.5765|1.9854|0.39822|
|B|2.6051|1.9493|0.39821|

两交点相距约0.04607 m。A的自旋模长由138.591 rad/s降至78.171 rad/s。两组初始自旋均超过2007年实测范围，初始Sp约0.4677；这项外推在论文、结果JSON与图中说明。没有通过裁剪系数或调整题目坐标制造范围内的拟合。

四个固定真实事件分别得到球门平面误差1.0089 m、8.2430 m、先触地、3.4780 m。三个到达案例均值4.2433 m。只用0、0.04、0.08 s位置拟合，后续位置仅确定真实球门平面交点。保留较大的早期残差和病态 Jacobian，不将这些事件包装成精确验证。

敏感性采用速度±5%、方向±2°、初始自旋0–2倍和角阻尼0.5–2倍的确定性扰动；这些是数值实验设计，不是参数概率分布。无旋转表面对照采用新Teamgeist零旋转阻力和原光滑球关系；两者预测高度分别1.9261 m与1.9448 m。

## 文件与复现

新结果全部写入 `results/coupled_model/`。其中 `problem` 保存19次起点结果、候选状态、轨迹、自旋、系数、力矩和残差；`real` 保存四事件的输入与每次拟合；`sensitivity` 和 `surface` 保存确定性比较；`figures` 保存PDF、SVG和300 DPI PNG。

```powershell
$env:PYTHONPATH='src'
python scripts/coupled_compute.py
python scripts/coupled_plot.py
python scripts/coupled_paper_values.py
python scripts/coupled_verify.py
python -m pytest -q
cd paper
xelatex -no-shell-escape -interaction=nonstopmode -halt-on-error main.tex
xelatex -no-shell-escape -interaction=nonstopmode -halt-on-error main.tex
```

`paper/coupled_results.tex` 由保存结果自动生成，正文的结果表和关键数值引用该文件。绘图不重新积分。

其他旧结果目录保留历史探索记录，未作为当前论文数值来源。旧概率采样和先验结果不进入当前计算。`linthorne_patel_coefficients` 为历史函数；M5的默认配置和当前论文入口均使用完整耦合模型。旧输出与当时源码的完整快照另保存在项目主目录的“耦合前存档”压缩包中。
