# 真实点球：完整飞行轨迹与球门位置对照

## 这次要检验什么

足球离脚后，重力使球下落，空气阻力改变球速，自旋会使球向侧方或上下偏转。可以把这些作用放入运动方程，计算球从点球点附近飞到球门的轨迹。为了先检查这个物理模型是否能描述实际飞行，本次使用一条真实点球的整段追踪记录来拟合模型，然后比较整条轨迹和球门平面上的位置。

## 真实点球与球门

样本来自 [DFL 公开比赛追踪数据](https://huggingface.co/datasets/pysport/idsse-data)的 J03WOH 比赛，事件记录标注为成功点球。球场大小为 105 × 68 m、坐标原点在球场中心，目标球门平面为 `x = 52.50 m`。本次使用帧 128954–128965，共 12 帧，包含球首次经过门线后的第一帧。相邻记录间隔 0.04 秒。

两帧在门线两侧，将球位置线性插值得到球心位于 `(x,y,z) ≈ (52.50, 2.919, 1.179)`。这里横向坐标以球门中心为零，高度 Z 暂按米处理；原论文明确 Z 为高度，但未找到明确的单位及球心基准说明。点球事件时间比选取的首帧早 0.88 秒，因此实际离脚时刻根据轨迹变化判断，首帧附近可能存在时间对齐误差。样本核查见《真实点球样本与物理模型核查》。

## 模型与方法

把首帧位置作为各模型起点，使用这 12 帧的全部位置确定模型参数。M1 加入重力，M3 加入重力和阻力，M4、M5 再加入旋转产生的力；M2 是匀加速度曲线，供比较。M5 使用 Linthorne–Patel 论文给出的系数关系。

M0、M1、M3、M4、M5 比较中只拟合初速度；其中 M4、M5 的自旋设为 `(0,0,30)` rad/s。另增加一项 **M5 参数拟合**：在同一条完整轨迹上拟合初速度、自旋与零自旋阻力系数，约束后者在 0.1–0.2。这里的位置误差为三维欧氏距离；门线误差为同一 `x = 52.50 m` 平面内的横向和高度距离。

## 对照结果

| 模型 | 整段三维位置均方根误差 / m | 门线位置 (y,z) / m | 门线位置误差 / m |
|---|---:|---:|---:|
| M0 匀速 | 0.255 | (2.783, 1.362) | 0.228 |
| M1 重力 | 0.204 | (2.783, 1.244) | 0.151 |
| M2 匀加速度 | 0.146 | (2.910, 1.194) | 0.018 |
| M3 重力和阻力 | 0.263 | (2.780, 1.236) | 0.150 |
| M4 固定系数与自旋 | 0.235 | (2.890, 1.236) | 0.064 |
| M5 固定自旋与论文系数 | 0.233 | (2.905, 1.237) | 0.059 |
| M5 参数拟合 | 0.194 | (2.868, 1.202) | 0.056 |

曲线与实测点见 `results/real_penalty_fit/trajectory_fit.png`，逐帧坐标与参数见同目录 CSV、JSON。模型参数拟合中，阻力系数到达设定下界 0.1，不同参数组合的作用也可能相近；拟合出的自旋仅用来描述这条轨迹，自旋没有独立实测。首帧到下一帧的位移明显小于后续帧，提示离脚时刻可能处于采样间隔内，这也会影响按首帧固定起点的拟合。

以上数值是**完整实测轨迹参与拟合后的贴合程度**，当前阶段用它检查模型与物理记录的吻合。今后研究提前预测时，再单独设计只使用预测时刻之前观测的实验。

## 复现

已有小型样本文件时，在仓库根目录运行：

```powershell
$env:PYTHONPATH='src'
python scripts/fit_real_penalty.py
python scripts/plot_real_penalty.py
python -m pytest -q
```

样本及事件来源、重新提取方式见 `scripts/inspect_real_penalty.py` 和《真实点球样本与物理模型核查》。计算与绘图分开；绘图直接读取已保存的拟合结果。
