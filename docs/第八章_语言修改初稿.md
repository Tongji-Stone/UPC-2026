# 第八章 模型评价

## 8.1 模型优点

**受力机制与轨迹变化相联系。** 模型将重力下落、阻力减速和旋转偏转纳入同一运动方程，能够从受力方向及大小的变化解释轨迹的弯曲。四模型对照进一步展示了不同受力描述和恒加速度近似对预测结果的影响，使低空推射与较高抽射的轨迹差异具有明确的物理解释。

**早期反演与后续检验相衔接。** 模型利用三个早期位置估计初始运动和相关参数，再通过相应运动方程计算后续轨迹。其后的实测位置用于比较路径与球门交点，使早期拟合和后续预测形成完整的检验过程。统一的坐标系、触地判据和球门穿越判据，也使不同模型及射门案例的结果便于比较。

**同时分析参考预测与交点变化范围。** 单参数扫描区分了各因素对交点和到达时间的影响；位置约束搜索展示了不同参数组合匹配早期位置后产生的预测差异；联合扰动则给出设定范围内的交点分布。三种分析相互衔接，将参数变化与最终预测联系起来，使结果包含参考交点、变化趋势及分布范围。

## 8.2 模型缺点

**初始运动与气动参数存在耦合。** 较短观测时段内，初速度、自旋和气动参数可以相互补偿，使位置接近的轨迹在后续飞行中逐渐分离。线性升力关系中，自旋大小与升力参数以乘积进入气动力，也使不同参数取值可能对应相同轨迹。增加早期追踪位置并直接测量自旋，有助于进一步约束初始状态和气动参数。

**气动力与环境条件经过简化。** 主模型将阻力系数和线性升力参数视为单次飞行内的常量，并采用静止空气和恒定自旋设置。实际飞行中的流动转捩、球面朝向与尾流波动会改变气动力，风和旋转阻尼也会影响相对气流及自旋演化。对这些过程作更细致的描述，需要结合球型专用气动数据、风速和自旋测量。

**实测样本覆盖有限。** 实测检验覆盖两次推射和一次大力抽射，增加不同球型、射门方式及风况下的追踪记录，可进一步考察模型在更多工况中的表现。联合扰动采用九项参数独立均匀抽样；后续可由实测数据估计参数分布及相关性，使模拟交点分布更贴近实际射门条件。
