英文 `paper/main.tex` 与中文 `_中文版/main.tex` 原位同步，保持单文件正文、字体、分式和缩进设置。

第四章依次为 4.1 求解方法（模型选取、反演方法、数据集）、4.2 案例分析（精准推射、大力抽射）、4.3 题设数据反演。M1/M2/M3/M4 的实际未知量仍为 3/4/6/7 项，共享动力学和 `fit_early` 未修改。M4 自旋模长仍为 30 rad/s。

三次真实点球的 39 条原始记录、选点和 12 组反演均保持不变。J03WMX、J03WR9 归为精准推射，J03WOH 归为大力抽射。正文增加球员、比赛和日期；输入表列出两次后续位置及实测球门交点。旧综合误差表改为推射 8 行、抽射 4 行的交点对照表，触地或未到达不记作球门交点。

最终图件布局：推射的两幅三维图左右并排；抽射的三维图与三个坐标时间曲线采用 2×2。抽射生成时检查三维标注与右侧坐标轴间距。两类踢法各一张速度、阻力、升力三面板图，时间和纵轴尺度一致；题设仅绘制 M4 三维轨迹。

踢法引用 Hunter 等（2018），DOI: 10.3390/sports6030073。抽射球速为 32.05 m/s、仰角 10.46°；两次推射球速为 29.20、28.34 m/s，仰角为 1.08°、3.83°。正文重点分析竖直初速度和马格努斯力方向。

## 复现

仓库根目录把 `src` 加入 `PYTHONPATH` 后执行：

```powershell
python scripts/chapter4_compute.py
python scripts/four_model_plot.py --chapter4-only
python scripts/four_model_paper_values.py
python scripts/verify_chapter4.py
```

第一步核对 12 组冻结反演，并用同一 `fit_early` 重新计算题设 M4，保存至 `results/current_report/problem/`。初始状态、六组起点结果、配置和轨迹随结果保存。新交点与第五章参考交点相差小于 1 微米，到达时间差小于 10 纳秒。第五章原计算和图表保持不变，开头改引 4.3。

第二步仅读取保存结果绘图；第三步刷新两版数值宏和表格。`results/current_report/chapter4/physical_summary.json` 保存初始速度、仰角、竖直速度、气动力和旋转轴；`verification.json` 记录 101 项数据与源文件核验。图像导出 PDF、SVG 和 300 dpi PNG。

最后在编辑器中分别编译两个 `main.tex`。编辑器编译诊断与本地已导出的 `main.pdf` 分别记录；源文件检查不读取旧 PDF。早先核查文件对应各自修订时的版本，本轮以 `chapter4/verification.json` 为准。
