# 跨比赛真实射门：参数数量匹配的轨迹对照

同一条实测轨迹可以同时用匀加速度曲线和包含阻力、自旋力的物理模型拟合。为比较两者对已记录飞行的贴合，下面让两类模型各调整六个分量：M2 调整初速度和匀加速度；M5 调整初速度和自旋，零自旋阻力系数固定为 0.18。两个模型都固定首帧位置，并使用从同步帧至首次穿越球门平面后第一帧的全部位置。

## 数据与筛选

使用 [DFL 开放比赛数据](https://doi.org/10.1038/s41597-025-04505-y)中的 J03WOH 和 J03WQQ 两场比赛。原始位置数据以 25 Hz 记录；事件 XML 与位置 XML 在同场内通过同步帧和时间对齐。场地均为 105 米长，以球场中心为坐标原点，球门平面为 `x=±52.5 m`。Z 是球高，单位暂按米处理，仍需核实球高的精确定义及单位。

每场使用同一固定筛选：射门事件有同步帧且同步时间与事件时间差不超过 1 秒；同步帧后 2 秒内首次向前穿越相应门线平面；记录至少 8 帧，间隔 0.04 秒，球高不低于 0.11 米，逐帧速度 2–45 米/秒，且持续向门线前进。射偏或射高可以穿过门线的延长平面，不能算作进球。筛选同时记录未入选原因；数据仅凭这些条件仍无法单独确认中途没有接触。原点球事件没有同步帧，因此按本轮统一规则排除，作为此前单独的点球示例保留。

J03WOH 的 27 个射门事件中，3 条入选；J03WQQ 的 27 个射门事件中，1 条入选。J03WQQ 的另一场数据已真实下载并分析，位置文件为 356,219,423 字节。四条共同使用同一模型和筛选规则：

| J03WOH ...0487 | 头球 | 射高 | 15 | 0.025 | 0.030 | 0.011 / 0.034 |
| J03WOH ...0606 | 右脚 | 射偏 | 36 | 0.062 | 0.058 | 0.111 / 0.126 |

第二场头球与门线延长平面的插值位置为 `(y,z)=(-3.534, 6.442)`，高于横梁；该条事件同步时间比事件原时间早 0.97 秒，精确触球时刻需要视频确认。这里所列误差均为**整段参与参数拟合后的贴合程度**，M5 的自旋没有独立测量。两场比赛属于同一 DFL 数据集，不能称为两个独立数据源。

## 复现

J03WQQ 文件从 [DFL 公开镜像](https://huggingface.co/datasets/pysport/idsse-data)取得，位置原文件和提取后的完整球轨迹放在 Git 忽略的 `data/raw/`。运行：

```powershell
$env:PYTHONPATH='src'
python scripts/extract_dfl_ball.py data/raw/J03WQQ.xml data/raw/J03WQQ_ball.csv
python scripts/dfl_shot_goal_validation.py --output results/dfl_j03woh_fair
python scripts/dfl_shot_goal_validation.py --match J03WQQ --ball-csv data/raw/J03WQQ_ball.csv --event-xml data/raw/J03WQQ_events.xml --output results/dfl_j03wqq_fair
```

每场结果的 `summary.json` 保存事件筛选、坐标和各模型误差；`positions.csv` 与 `fitted_positions.csv` 保存实测和拟合逐帧坐标。原始文件来源、匹配方式和球场尺寸记录在各场比赛的 XML 中。
