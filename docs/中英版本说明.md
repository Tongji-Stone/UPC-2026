# 中英文论文版本

本次修订移除 Figure 1 底部的三力文字条，精简风洞实验介绍与两张图的图注，并将 CD、CL 的经验式、参数及适用工况收入对应物理量的 enumerate 条目。每项讨论以加粗的物理量名称开头。

- 英文分支：`codex/report-english-20261108`，论文位于 `paper/main.tex`、`paper/main.pdf`。
- 中文分支：`codex/report-chinese-20261108`，在英文基线上增加完整编译目录 `_中文版/`，论文位于 `_中文版/main.tex`、`_中文版/main.pdf`。

中文版翻译正文、表格和图注，图内文字与路线图按约定保留英文。字体按原文样式对应：正文宋体（SimSun）、粗体黑体（SimHei）、斜体楷体（KaiTi）。公式、计算结果和引用键与英文一致，数值比较和字体核验记录在 `results/bilingual_report/verification.json`。

## 编译

进入对应论文目录，运行三次：

```powershell
xelatex -no-shell-escape -interaction=nonstopmode -halt-on-error main.tex
```

两个目录均引用同一仓库的 `src/` 附录程序，因此应保留完整仓库。中文版另保存所需图表副本。

## 翻译复现

从英文分支运行 `python scripts/build_chinese_report.py` 可创建 `_中文版`。脚本检查英文源稿 SHA256，再应用逐段译文；后续若修改英文正文，应同步更新译文目录与 SHA256。`translation_catalog.json` 记录源文与译文对应关系。

在仓库根目录运行 `python scripts/verify_bilingual_reports.py`，检查加粗物理量条目、经验式归属、两版显示公式与表格数字、字体及编译日志。

第五章灵敏性分析继续保留待完成说明。当前修订不改变模型参数、计算程序和已保存模拟结果。
