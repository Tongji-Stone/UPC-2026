# 中英文版本同步

英文稿在 paper/，中文稿在 _中文版/，分别维护 main.tex、sections/model_solving.tex 和 sensitivity.tex。两版共享图件及数据，由相同 JSON/CSV 生成 report_results.tex、sensitivity_results.tex。

中文正文为宋体，加粗为黑体，斜体映射为楷体，英文为 Times New Roman。图内英文与当前分支样式保持一致。

verify_bilingual_reports.py 展开第四、五章，比较显示公式、引用键和数值表，并检查字体、引用和逐页排版。verify_sensitivity_integration.py 核对线性模型输入、源代码散列、图件、模拟样本及正文数据。完整生成使用 scripts/reproduce_report.ps1 -Recompute。

全文按用户指定的文章表述规则同步修改：具体写方法、结果和物理解释，统一定义条件和统计量，资料核查放在 check.md。规则来源见 文章表述修改依据.md。
