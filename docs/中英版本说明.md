# 中英文版本同步

英文 `paper/`，中文 `_中文版/`，各自维护正文与第四章译文，共享当前数据、动力学、反演入口及图表。`four_model_paper_values.py` 从相同 JSON 生成两个版本的数值宏；`verify_bilingual_reports.py` 比较显示公式、引用键、表格数字和字体。图表文字保持英文。

两分支为 `codex/report-english-20261108` 和 `codex/report-chinese-20261108`。中文分支包含两版，英文分支交付英文稿及全部通用数据/代码/结果。历史译文可在 Git 中回溯；当前编译目录只保留启用的资源。
