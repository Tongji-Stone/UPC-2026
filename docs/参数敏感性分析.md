# 飞行参数敏感性分析

预测足球到达球门的位置时，可以先给速度、阻力、自旋和风设置一组参考值，再分别改变其中一个量，观察落点如何移动。另一种方法是在设定范围内同时随机改变各量，查看可能出现的落点分布。本阶段采用这两种方法，为后续选择需要重点测量的量提供参考。

## 设置

从题目中 0.10 秒的球心位置 `(2.96, 0.86, 0.74)` m 开始计算，参考速度为 `(29.2, 8.2, 6.49)` m/s。参考零自旋阻力系数为 0.18，竖直轴自旋为 30 rad/s，横风为零；其他参数及扫描范围记录在 `results/sensitivity/config.json`。气动系数采用 [Linthorne 和 Patel（2011）论文](https://www.jssm.org/volume10/iss1/cap/jssm-10-203.pdf)第 3、4 式：令转速 f 的单位为转/秒，则升力系数为 `0.25 × (1 − exp(−0.5f))`，阻力系数为 `Cd0 + 0.014f`。论文讨论的零自旋阻力系数 0.1～0.2 对应速度约 25～35 m/s；论文以足球长距离凌空踢为研究对象，此处将其用于三维侧旋并加入自旋方向投影。升力倍率用于研究公式变化的影响，速度、自旋、空气密度、风和倍率的扫描范围由本次分析设定。

单因素扫描对球速、水平角、仰角、零自旋阻力系数、空气密度、升力倍率、三个自旋分量、自旋衰减率和三个风速分量共 13 个量分别取 11 个值，其余量保持参考值。随机扫描在各范围内独立均匀抽取 256 组，随机种子为 20261107。每次计算均记录先到达球门平面、先落地或在计算时间内未发生事件；本次随机扫描 256 组均先到达平面。

## 结果

在本次设定的范围内，水平角从 13° 增至 19°，球门平面上的横向位置增加约 0.960 m；仰角从 9° 增至 15°，高度增加约 0.911 m。竖直轴自旋从 0 增至 50 rad/s 时，横向位置增加约 0.496 m；y 轴自旋从 −20 增至 20 rad/s 时，高度降低约 0.494 m。不同参数采用的扫描范围不同，具体曲线见单因素图。

256 组随机扫描的球门平面位置范围为横向 2.764～4.181 m、高度 1.354～2.763 m。这组散点对应上面选定的演示范围和均匀抽样方式；若要给出实际预测概率，需要结合速度、自旋等量的测量误差重新设定抽样分布。

## 复现

在仓库根目录先运行 `python scripts/sensitivity_compute.py`，结果写入 `results/sensitivity/` 下的 CSV 和配置文件；再运行 `python scripts/sensitivity_plot.py`，从已有 CSV 生成两张图。绘图无需重新计算轨迹。
