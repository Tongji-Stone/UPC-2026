# 本文采用的表述规则

提取来源：`D:\知识库\作业\物理实验\讲义\experiment_skill\SKILL.md` 中“报告正文的表述边界”“使用容易理解的词语”和“删除不必要的保守性说明”。本次采用其中的写作指导，论文保留原有章节、字体和科学计量方式。

1. 正文按物理问题、方法、结果和解释展开。删除任务沟通、修改过程、工具验证、自我评价以及“沿用队友设计”等过程用语。
2. 用具体量、数值和现象说明结果，避免“体现了作用”“提供了重要依据”等空泛概括。
3. 对计算和数据支持的结果直接表述。说明一次参数范围、事件判据和统计量定义，后文直接引用。
4. 删除在结果后重复补充的“仅……”“不代表……”“不能证明……”及近义表述。缺参、待核实事项和内部核查说明放入仓库根目录的 `check.md`。
5. 保留决定公式和结论含义的条件：三力基准、恒定自旋、30 rad/s 参考模长、2 mm 约束残差、独立均匀扰动范围以及球门净空判据。
6. 图注说明变量、单位、颜色和曲线。正文解释图中趋势及相应的受力变化，删除图像判读提醒和重复的范围辩解。
7. 区分实测位置、反演状态和模拟分布。相同数据的重新处理称为复算，未测量的自旋不写成实测量。
8. 可能的误差原因与确定的观测结果分别表述。结论给出各案例实际误差和模型表现，不把三例比较扩大为普遍排名。
