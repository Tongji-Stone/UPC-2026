# 恒合力与线性自旋模型：重算说明

本次沿用队友更正起点后的三例点球数据与章节结构，M3 为恒合力、匀加速度，M4 使用恒定阻力系数和 CL = αSp。M4 以 30 rad/s 作为角速度模长的参考设定，同时拟合初速度、旋转方向、CD 和 α；系数参考值的倍数范围为 0.5 至 1.5。

题目三点的参考反演中，CD = 0.3623、α = 2.2877，两个参数均到达搜索上界，交点为 (2.6159, 1.9526) m。由于 α 与角速度通过乘积共同影响马格努斯力，位置数据不能将二者分别唯一确定。

灵敏性章节采用新的受力方程。九项参数各取 41 个单因素取值；条件扫描在参考系数倍数 [1.2,1.8] 上使用 17×17 网格，重新拟合速度与自旋，早期坐标最大残差不超过 0.002 m；联合扰动使用随机种子 20261108 和 100000 条轨迹。条件扫描是有限网格结果，统计比例对应所设定的均匀扰动范围。

计算输出在 results/current_report、results/sensitivity_linear 和 results/monte_carlo_linear；计算和绘图脚本分开。运行 scripts/reproduce_report.ps1 重新计算正向和比赛点球，运行 scripts/reproduce_sensitivity.ps1 -Recompute 更新灵敏性结果和两版 PDF。旧版 results/sensitivity_v2 和 results/monte_carlo 保留历史数据。
