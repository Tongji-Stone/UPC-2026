## 3. 摄像机机位、测量流程与精度

### 3.1 本数据论文明确提到的采集系统

依据论文第2页 Methods / Position data、第3页 Fig.1：

| 项目 | 论文报告 | 对本次三条点球的适用范围 |
|---|---|---|
| 系统 | ChyronHego TRACAB Gen5 多相机光学追踪 | 数据集整体使用的系统 |
| 摄像机数量 | 随球场为16–20台 | 未逐场给出这三次点球的具体台数 |
| 机位 | 球场两侧各6台；每个球门后方各2台；Fig.1为16台示意 | 为一般机位说明，不是三场的逐台坐标 |
| 图像分辨率 | 1920×1080像素 | 采用本数据论文报告值 |
| 采样频率 | 25Hz | 本次39帧相邻时间差均为0.04s |
| 坐标生成 | 多视角视觉检测/跟踪，标定后投影到场地坐标 | 发布坐标属于视觉测量结果 |
| 数据处理 | 提供方做异常值过滤、平滑与人工质量检查 | 本次 CSV 保留发布值，未再过滤或平滑 |
| 逐场标定细节 | 未给出每台相机的内外参、精确机位、高度、镜头焦距、曝光时间 | 不能据示意图补为精确标定参数 |

论文没有专门报告这三次点球的足球三维位置精度，也没有提供 Z 高度的独立误差、每帧误差条或这几次射门的高速球追踪标定结果。原 XML 中 X/Y/Z 通常保留两位小数，这是发布数值的量化形式，**不等于测量精度±0.01m**。

### 3.2 数据论文转引的精度验证

论文第6–8页 Technical Validation / Position data 转引 Linke 等的系统验证：以 VICON 为参考，在球场内30×30m区域进行跑动路线及小场比赛测试，汇总的位置 RMSE 为0.06–0.18m、速度 RMSE 为0.03–0.09m/s、加速度 RMSE 为0.06–0.27m/s²。该段讨论球员追踪，不能把这些数值直接当作本次点球足球、尤其足球 Z 高度的测量误差。

进一步核对的原始验证文献：Linke, D., Link, D., & Lames, M. (2020). *Football-specific validity of TRACAB’s optical video tracking systems*. PLOS ONE, 15(3), e0230179. [DOI及全文](https://doi.org/10.1371/journal.pone.0230179)。该研究测试20名男性球员，Gen5 球员位置 RMSE 为0.08m、速度为0.08m/s、加速度为0.21m/s²；不是足球飞行精度实验。

该验证文献的 Tested systems 报告测试现场 Gen5 安装高度16m、16台1920×1200像素相机；Criterion reference 报告33台 VICON 相机、100Hz和参考系统3D标定 RMSE 1.16mm。这些是**2020年验证实验的配置与参考系统精度**，并非本次三场比赛的实测配置。其1920×1200与本数据论文1920×1080分别保留各自来源，不合并成一个参数。

### 3.3 时间精度与同步

25Hz 表示每40ms一个位置采样，不代表已知每次离脚发生在采样格点。论文第8页的事件—追踪同步分析报告原始与同步后事件时间差约−0.37±1.82s，最大27.34s；这是事件标注对齐差异，**不是相机时间戳抖动或40ms采样误差**。CSV 的相对时间直接用源追踪时间戳相减，没有套用论文同步算法。

三次起始帧相对原始事件时间分别为−0.60s、+0.88s、+0.04s，汇总表逐条保存；因此没有把事件时间当作离脚瞬间。

## 4. 坐标、起始位置和球门位置

保留 DFL 球场中心水平坐标：水平原点 `(X,Y)=(0,0)`，X 沿球场长度，Y 沿宽度。本次三次射门朝正X方向，不平移、不旋转。关于 DFL 以球场中心为水平原点的约定，可参见 [Space and Control in Soccer，3.1 Data](https://www.frontiersin.org/journals/sports-and-active-living/articles/10.3389/fspor.2021.676179/full)。

X/Y 单位为米，见本地论文第5页 Position data。Z 在论文中称为球高，没有明确列出单位或球心/球表面参考点，因此 CSV 使用 `Z_原值` 字段，`垂直原点Z_m` 留空。若后续将 Z 视为米及球心高度，应在分析中显式声明。

三场比赛原始 `Environment` 给出球场105×68m，因此正X门线为X=52.5m。按规则，球门四角的几何坐标为 `(52.5,-3.66,0)`、`(52.5,3.66,0)`、`(52.5,-3.66,2.44)`、`(52.5,3.66,2.44)`，此处 Z=0 专指门框几何的地面基准，不能据此声称来源足球 Z 的参考点已独立核实。

起始位置采用该次点球首个可用的比赛进行中追踪帧，令 t=0；精确离脚初始位置三列均留空。名义点球点地面坐标 `(41.5,0,0)` 单列，未替换成球的实测起始位置。

## 5. 球参数与踢球姿势

来源未给出逐球实测半径或质量，故实际半径和实际质量列留空；规则上下限放在带 `IFAB` 前缀的独立列。没有用常见建模值0.11m或0.43kg冒充实测参数。

原事件明确给出的 `TypeOfShot`：Ljubicic 为 `rightLeg`、Kownacki 为 `rightLeg`、Klement 为 `leftLeg`，分别译为右脚、右脚、左脚。三次 `PenaltyExecution` 均为 `targetedShot`。这是官方事件分类，不是人体姿态测量。来源没有提供助跑角、支撑脚角、关节角度、上身前倾、触球脚面部位或实测自旋，故不进行推断。论文第2页说明赛事视频未在此数据集中公开，不能凭空补写详细动作。

插值仅用相邻实测帧：`a=(52.5-X1)/(X2-X1)`，再计算 `Y=Y1+a(Y2-Y1)`、`Z=Z1+a(Z2-Z1)` 和时间。此处“穿越”指球的位置参考点到达门线平面，不另行计算整个足球完全越线的时刻。

完整采样中没有插入这些插值穿越点：每行都对应真实源帧。门线后的记录可能进入球网或其他接触阶段，已用 `位置区段` 标明，使用自由飞行模型时可按研究范围选取。

## 8. CSV字段与读取说明

- 汇总表中带 `起始`、`时刻1`、`时刻2` 的坐标直接来自对应源帧；`球门穿越` 坐标按来源列区分直接记录与插值。
- 位置表每行一帧，`源帧号_N`、`源时间戳_T`、`X_m`、`Y_m`、`Z_原值` 与原 XML 一致。
- 原 XML 的 D 为厘米、S 为km/h、A 为m/s²、M 为比赛分钟，单位依据论文第5页。这些字段原样保留，没有重新计算速度和加速度；是否等于位置差分结果由数据提供方流程决定。
- `源球权_BallPossession`：1为主队，2为客队；`源比赛状态_BallStatus`：0为比赛中断，1为比赛进行中。本次39帧均为1。
- `是否与上一帧位置重复` 与 `是否汇总选用时刻` 使用0/1标记。重复帧没有删除。
- 数值缺失采用空单元格，不写0；“未提供”的原因写在相邻说明列或本文件。源帧号与事件ID建议按字符串/整数读取，事件ID不要用Excel显示出来的科学计数法文本覆盖原文件。
- CSV中的坐标保持源发布小数，插值位置保留数值计算精度；更多小数位不表示更高测量精度。

导出检查：3次点球的帧号连续；每组追踪时间间隔0.04s；39行坐标及全部保留源字段逐值比对原始下半场 BALL 元素；两个选用时刻和起始观测均在完整采样表中。没有仿真、物理模型预测、后向外推或补造缺失坐标。
